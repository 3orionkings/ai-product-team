# Third-party notices

This repository contains no third-party code and no third-party text.

- **Runtime dependencies:** none. The tools and the experimental library use only the Python standard library.
- **Host formats:** the generated files follow the documented formats of Claude Code (subagents and skills), Codex (custom agents and skills) and the open Agent Skills specification. Those documents were read to learn the formats; no text from them is reproduced. Links are in `docs/compatibility/README.md`.
- **Adapted material:** eleven method skills adapt the author's own unpublished 2026 drafts. They are listed by content hash in `registry/sources.public.json` and released here under the MIT License.
