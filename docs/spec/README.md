# Design specification (v0.1 inputs)

These five documents are the design package the build was executed from, dated 16 October 2026. They describe a system *to build*; they are not a record of what the repository has verified. Where the implementation and these documents disagree, the implementation's own documentation and tests are authoritative, and the divergence is listed in `docs/architecture/divergences.md`.

The package also contained a private build prompt and a private source map, which are not published. Two referenced files (`00_START_HERE.md`, `08_SOURCE_NOTES.md`) and the registry/schema seeds were not supplied; the registries under `registry/` were reconstructed and say so in their `reconstruction_note` fields.

**Redaction note.** Four sentences in the public copies of the PRD and architecture originally named an unrelated private project of the owner in their exclusion clauses. The public copies replace that name with a generic phrase; the meaning (that the material is excluded) is unchanged.
